## Overview

In this prep, you will get familiar with **MongoDB**, the database we will use for both the personal and group projects.

MongoDB is a **document database**. Unlike a relational database, which organizes data into tables and relationships between them, MongoDB stores data as documents. These documents can contain values, arrays, and nested documents, making it possible to represent structured application data in a flexible way.
