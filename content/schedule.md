## Course Structure

The course is organized around lectures (L), recitations (R), assignments, and preps.

### Early Topics (September)

- Problem framing and conceptual design
- Behavior design and modularity principles
- Human-AI interaction fundamentals

### Mid-Course (September-October)

- AI-powered feature design
- LLM APIs and coding concepts
- Backend architecture with MongoDB
- Frontend frameworks and HTML/CSS

### Later Topics (October-November)

- Visual design principles
- Software engineering practices
- User testing and value-sensitive design

### Final Project (November-December)

Team-based design project with multiple checkpoints, including problem framing, pitches, functional design, alpha/beta releases, user testing, and final demonstrations.

The course culminates in a project fair on December 10.
