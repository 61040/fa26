For this checkpoint, in addition to submitting the code and updated designs, you will submit the following (1) a public URL pointing to your deployed app; (2) a screen recording showing the current state of your app, with an audio narration explaining some key features, and (3) a new version of the development plan explaining what progress you've made, what remains to be done, and how your plans might have changed.

Your beta checkpoint should be a functionally complete version of your implementation. It should be deployed.

Deliverables are submitted as follows:
- **Source code, updated designs and updated development plan**: in the team repo, provided as a Git commit hash
- **Deployed app**: a separate link to the running, deployed app
- **Screen recording**: a separate link to a video recording, but also linked in the readme of the submitted repo
